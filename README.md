# 🛡️ Detector de SQL Injection em Python

Meu primeiro projeto de Cibersegurança!

### 📖 Sobre o projeto
Este programa analisa trechos de codigo e identifica tentativas de SQL Injection, uma das vulnerabilidades mais comuns da web.

Ele detecta ataques como:
- `or '1'='1'`
- `DROP TABLE`
- `DELETE FROM`

### 🚀 Como usar
py detector.py

### 💻 Tecnologias
- Python 3
- Validacao de entrada e logica de seguranca
